# Judgments are derived by written rules, never recorded

The Rally Log holds only Observed and Inferred facts. Judgments such as drop success, unforced errors, popups and Rally Phase are Derived by written rules in Event Processing. Hand-tagged judgments drift between people and over time, and a model can't be benchmarked against a moving target; a rule can be changed and re-run over every Match ever annotated. The one judgment kept in the Rally Log is Shot Class, because a Shot has to be classed somehow before any rule can run.

## Considered Options

- Tagging "unforced error" and "shot success" by hand, as most stat sheets do: rejected for the reasons above.
