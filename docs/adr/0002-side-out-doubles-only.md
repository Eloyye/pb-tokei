# Only side-out-scored doubles is in scope

We cover PPA, APP and MLP doubles Matches played with side-out scoring. Singles, MLP DreamBreakers, and any Match played with rally scoring (including earlier MLP seasons) are out. The core stats depend on doubles-only ideas (a Team arriving at the kitchen, the Returner's transition) and on side-out structure (only the Serving Team scores, first and second server), so adding another format would change what existing stats mean, not just add more data.
